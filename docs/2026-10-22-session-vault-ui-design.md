## 1. 放在哪里

| 问题 | 答案 |
| --- | --- |
| 主入口 | **侧栏面板行**：`sidebar.panellist` 增加「会话保险库」（与 Plugins / Cron 同款原生行），点击在主列打开完整面板 |
| 快速搜索 | `sidebar.footer.action` 放大镜按钮 → 覆盖层搜索（Ctrl / Cmd + Shift + K，P3 起；普通 Ctrl+K 归宿主），搜索范围与面板一致（所有工作区会话 + 归档 + 冷存）；结果可直接打开 / 迁移 / 恢复 / 预览 |
| 是否接管会话列表 | **否**。`sidebar.workspaces`（工作区与会话列表）属于 ui-workspace，better-sidebar 也在这一层；我们只用独立 seat |
| 会话头部 | `conversation.session.header.utilities` 放一个 🔍 按钮（用户 2026-10-22 确认“可以加”），任意会话里一键呼出同一个搜索 |
| 设置页 | 保留 `settings.section`：配置（冷根 / 阈值 / 自动迁移 / 日预算 / 跨卷 / 透明水合）+ 第三方侧栏不渲染 panellist 时的兜底入口 |
| 搜索范围 | **所有工作区会话（热）+ 归档 + 冷存**，统一自建索引，按 `(size,mtime)` 增量 |
| 筛选维度 | 全部 / 热归档 / 冷存储 / 收藏 / **工作区**（下拉；用户头号关切是那三个工作区） |
| better-sidebar 兼容 | 只用标准 slot 注册；它渲染原生侧栏时两个入口都在；若它完全替换侧栏，则自动回退到设置页 + 快捷键（不写 DOM 补丁、不抢 `sidebar.workspaces`） |
| 深链 | `ctx.layout.selectPanel('session-vault')`；快捷键注册在 `ctx.shortcuts` |

## 3. 交互矩阵

| 动作 | 前提 | 反馈 | 失败 |
| --- | --- | --- | --- |
| 搜索 | — | 300ms 防抖；结果按会话分组，命中行高亮；空结果给「没有符合条件的会话」 | 索引未建完 → 顶部提示「索引构建中 N/M」 |
| 筛选 chip | — | 立即过滤；与搜索叠加 | — |
| 勾选 / 全选 | — | 顶部批量条出现，显示「已选 N 项」 | — |
| 归档 | 未归档 | 行状态变「已归档」，记录 archivedAt；可勾选「归档并迁移」 | 活跃会话 → 提示「会话正在运行，先停止再归档」 |
| 取消归档 | 已归档且热 | 行消失（回到官方列表）。**冷会话**被官方 UI 取消归档时（D-16′ 已采纳）：当场搬回热目录并提示「已搬回热目录」；开关关闭时 ⇒ 顶部横幅列出被外部取消归档的冷会话 + 一键恢复 | 搬回失败 ⇒ 明确报错「恢复失败：<原因>」，**绝不静默消失** |
| 迁移 | 已归档 + 热 + 非活跃 | 进度（字节/百分比）→ 状态变「冷存储」；manifest 一行 | 失败 → 行标红 + 原因（占用/权限/校验失败），可重试 |
| 批量迁移 | 多选 | 串行执行（并发 1），逐行进度；完成后汇总「成功 N / 失败 M」 | 单条失败不阻塞其余 |
| 恢复 | 冷存储 | 「恢复中」→「已恢复（热）」；随后官方列表可见 | 身份校验失败 → 提示「**已恢复到磁盘原位；重建工作区后重试挂回**」+ 提供「重试挂回」入口；文件不回滚 |
| 预览 | 任意 | 右侧抽屉显示最近 N 条 / 命中上下文；不恢复、不打开会话 | 日志损坏 → 「无法读取：帧损坏（第 N 帧）」 |
| 收藏 | 任意 | 星标 + 收藏筛选（置顶仅「按时间」排序时生效） | — |
| 永久删除 | P3，冷存储 | 二次确认 → 进回收站 | 回收站可还原 |

## 4. 状态与文案

| 状态 | 表现 |
| --- | --- |
| 首次进入（索引为空） | 列表来自 registry + 磁盘元数据，秒出；顶部提示「全文索引构建中」 |
| 无归档 | 空态：「还没有归档会话。归档后超过 14 天会自动进入冷存储。」 |
| 冷目录不可用 | 顶部黄条：「冷存储目录不可用：D:\…（只读模式，不会删除任何数据）」 |
| 检测到 AM 插件 | 顶部黄条：「检测到 archive-manager，自动迁移已暂停（它会删除缺失工件的归档标记）。」并注明「归档时间改用轮询记录，取消归档不会自动搬回」 |
| 冷会话被外部取消归档 | 顶部横幅：「N 个冷会话已被外部取消归档」+ 一键恢复 |
| 第 14 天后可迁量很大 | 顶部统计显示「今天可迁 N 个 / X MB」；超出每日预算（默认 20 个）的顺延到明天 |
| 透明水合开关（D-16′ 已采纳，默认开） | 若该开关随 D-16′ 一并落地，设置页显式标注「关闭后，官方取消归档不会自动把冷会话搬回」，并给风险说明 |
| 迁移中 | 行内进度 + 「可关闭页面，后台继续」 |
| 错误 | 行内红色原因 + 「重试」；错误同时写日志 |

## 5. 组件与实现约定

- React 组件挂在 `settings.section` slot；宿主端零配套（除 HTTP 路由）。
- 复用官方 primitives（按钮/输入/开关/表格样式），不引入新 UI 库；颜色全部走宿主 token。
- 列表用虚拟滚动（>200 行时），每行高度固定。
- 所有写操作按 id 去重、乐观更新 + 失败回滚显示。
- 键盘：Tab 可达、空格勾选、Enter 打开预览、Esc 关抽屉。
- 窄屏（<900px）：设置左栏收起；抽屉改为底部整宽面板。

## 7. P4 子代理会话冷存（2026-10-27 设计定稿）

**入口 1：设置页「子代理会话冷存」卡**（`settings.section` 内新增一段，与现有配置表单同页）

| 元素 | 交互 |
| --- | --- |
| 开关 `subagentMigrate` | 默认关；开启前弹二次确认（文案写明「只搬未登记 + 未被引用 + ≥N 天未活跃的子代理会话」） |
| 阈值 `subagentAgeDays` | 数字输入（0 = 关闭）；右侧实时显示「当前会命中 N 个 / X MB」 |
| 预算 `subagentDailyBudgetCount` | 数字输入（仅自动清扫使用） |
| 只读读数 | 候选 N 个 / X MB；已冷存 M 个 / Y MB；上次扫描时间；gaps 数（非 0 时黄条说明会暂停） |
| 「立即扫描」 | 调 `subagent-scan {action:start}`，显示进度与完成时间 |
| 「迁移候选」 | 二次确认弹窗列出数量与字节 → `subagent-migrate {all:true,confirm:true}` → 进度条 + 可取消 |
| 卡顶部**恢复入口指路** | 一行「列表 / 预览 / **恢复**入口在主面板（侧栏「会话保险库」），本页只放配置」+「打开主面板」按钮（2026-10-27 用户实测：在设置页找不到恢复冷会话的入口；同时覆盖 class A 冷会话） |

**入口 2：主面板顶部两个 chip**：`归档会话`（默认，行为不变）/ `子代理会话`

- 子代理页两段：**候选**（热，行操作 = 迁移）与**已冷存**（行操作 = 恢复 / 预览）；
- 行状态文案：`hot-subagent` → 「热·可迁移」，`cold` → 「冷存」；
- 空态：「没有符合条件的子代理会话」+ 年龄阈值提示；
- 暂停/缺口：顶部黄条给出原因，**四条全列**（`subagent-refs-incomplete` / `cold-unavailable` / `cross-volume-disabled` / `restoring-unsettled`）；
- **gaps 解除路径**（评审 #4 裁定 A）：黄条内列出 gap 的会话 id 与原因，并提供「重新扫描」按钮；用户修好/移走坏目录后重扫，`gaps` 清零即自动解除（不做静默豁免）。

**文案红线**：子代理页必须写明「搬到冷存后，宿主的会话列表与父会话的子代理缩进行不再显示它们；可在本页或全局搜索找回」。

### 7.1 列表排序切换（2026-10-28 用户反馈）

**问题**：归档会话列表按「最近活跃」平铺，跨工作区交错，用户反馈「没按原来工作区分类，看着比较乱」。

**决策**：在列表工具条加一个排序切换：**按工作区（默认）** / 按时间。

- 「按工作区」：按工作区标签分组排序（同组内按上次活跃倒序）；工作区仍由现有「工作区」下拉筛选，不新增分组头（避免破坏窗口化列表的固定行高）。
- 「按时间」：保持现状（收藏优先 + 上次活跃倒序）。
- 窗口化（>200 行）与固定行高不变；排序只改顺序，不改渲染结构。
- 「按工作区」模式下收藏不再置顶（分组优先）；收藏仍可用筛选 chip 查看。
